# Computing Without Computers

A static website by Aven-Le Zhou presenting the three taught VIS104 studies in Weeks 03–05.

Each week has three distinct parts: Lecture, Lab (execution of a classic work), and Exercise (an original student-designed work). Images show credited historical references.

## Preview and upload

Open index.html directly, or serve this directory with a static server. All four HTML files contain their own styles, images and image-viewer code. A weekly page can be copied elsewhere and viewed independently; navigation to other pages requires the directory structure. Source links open external websites.

Upload the contents of this directory to your GitHub Pages publishing directory. Keep index.html at its root alongside week-03, week-04 and week-05. Links are relative and support repository subpaths. No build, CDN, account, API key or programming-demo dependency is required.

The package excludes course slides, guides, teaching notes, templates and project downloads. CREDITS.md records artwork sources. The website is prepared for the instructor to publish; no hosted website has been created.
